Les couleurs du quartz : // un même minéral, plusieurs histoires géologiques.
Le quartz est l’un des minéraux // les plus répandus dans la croûte terrestre.
Sa composition chimique est relativement simple : // du dioxyde de silicium, SiO₂.
Pourtant, il peut présenter // une étonnante diversité de couleurs.
Du cristal parfaitement transparent // au noir profond du morion,
en passant par les nuances violettes de l’améthyste // ou les teintes brunes du quartz fumé.
Mais d’où viennent réellement ces couleurs ?
Commençons par le quartz morion.
Cette variété très sombre, parfois presque noire, // doit sa coloration
à des phénomènes liés // à l’irradiation naturelle.
Au cours de son histoire géologique, // le cristal a été exposé à des rayonnements
provenant notamment d’éléments radioactifs // présents dans les roches environnantes.
Ces rayonnements modifient certains défauts // de sa structure cristalline,
notamment autour d’impuretés // liées à l’aluminium.
Ces centres colorés absorbent // une partie de la lumière,
donnant au quartz // son apparence très sombre.
Le quartz fumé // présente un phénomène comparable.
Sa couleur varie du gris clair au brun profond, // parfois avec des nuances presque chocolatées.
Là encore, l’irradiation naturelle intervient // dans la formation de centres colorés
au sein du réseau cristallin.
La différence d’intensité de la coloration // dépend notamment de la composition du cristal,
de son exposition aux rayonnements // et de son histoire géologique.
Passons maintenant à l’améthyste.
C’est probablement l’une des variétés de quartz // les plus reconnaissables,
grâce à ses teintes violettes.
Sa coloration est principalement liée // à la présence de traces de fer
dans le réseau cristallin.
Sous l’effet de l’irradiation naturelle, // certains ions de fer perdent un électron
et forment des centres colorés, // qui absorbent certaines longueurs d’onde de la lumière.
C’est cette absorption sélective // qui donne naissance aux différentes nuances de violet,
allant du lilas très pâle // au violet intense.
Le quartz blanc laiteux // possède une origine différente.
Contrairement aux variétés colorées // par des centres de défauts cristallins,
son apparence blanche est principalement due // à la diffusion de la lumière à l’intérieur du cristal.
De minuscules inclusions, // notamment des fluides emprisonnés lors de sa croissance,
peuvent perturber le passage de la lumière // et lui donner cet aspect blanc, opaque ou translucide.
Plus ces inclusions sont nombreuses, // plus l’effet laiteux peut être prononcé.
Enfin, le quartz transparent, // également appelé cristal de roche.
Sa transparence s’explique par sa faible absorption // et sa faible diffusion de la lumière visible.
Lorsque le cristal contient peu d’impuretés absorbantes // et peu d’inclusions microscopiques,
la lumière peut le traverser // presque sans être dispersée.
Il révèle alors toute la limpidité // de sa structure cristalline.
Finalement, ces différentes variétés nous montrent // qu’un même minéral peut raconter plusieurs histoires géologiques.
La composition reste essentiellement la même, // mais les impuretés, les défauts cristallins,
les rayonnements naturels et les conditions de croissance // transforment profondément son apparence.
C’est toute la richesse de la minéralogie : // comprendre ce qui se cache derrière la beauté d’un cristal.
