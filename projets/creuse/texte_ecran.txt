Minéraux de la Creuse : // dix gisements de ma collection.
Premier arrêt au nord : // Crozant, aux portes de la vallée des peintres.
Ici, une calcédoine rouge en mamelons, // une forme de quartz.
Elle est faite de fibres de quartz // si fines qu'on ne les voit pas.
Ses teintes rouges // viennent d'oxydes de fer.
Tout près, à Anzême, // une trouvaille anecdotique, mais je tenais à la montrer.
Des cubes de fluorite jaune-brun : // un fluorure de calcium, de dureté 4.
À l'est, Montebras, // sur la commune de Soumans.
Son étain est connu // depuis l'Antiquité, selon les sources.
De 1868 à 1914, ses mines // livrent environ 300 tonnes d'étain.
Le gisement a donné son nom // à un minéral : la montebrasite.
Ici, un grand cristal de quartz, // le minéral le plus commun de la croûte terrestre.
Puis de l'apatite violette, // un phosphate de calcium riche en manganèse.
La turquoise et la wavellite // naissent de l'altération des phosphates de lithium.
La wavellite forme // ces gerbes rayonnantes.
Et voici une fluorite violet très sombre, // posée sur un tapis rosé de dolomite.
À l'ouest, Janaillat // et son granite orbiculaire.
Une roche rare : // le granite y forme des boules.
Chacune alterne // des couches claires et sombres, comme un oignon.
Au centre, Lavaveix-les-Mines, // un village né du charbon.
Concédé en 1817, // le bassin est exploité jusqu'en 1969.
La production culmine en 1874, // à 354 000 tonnes.
En 1876, la compagnie // emploie 2 000 ouvriers.
La mine produisait // sa propre électricité.
J'y ai cette pyrite, // un sulfure de fer, très rare sur ce site.
Tout près, une carrière d'Ahun // a livré cette calcite, un carbonate de calcium.
Elle porte de l'analcime, // en cristaux blancs à 24 faces.
À l'est, Saint-Silvain-Bellegarde // et sa carrière de granite.
Ici, une gerbe de quartz // coiffée d'oxyde de fer, puis de la calcite.
Au sud-est, Flayat // et l'étang de la Ramade.
Sa fluorite violette // forme un tapis de petits cristaux.
À Gioux, Hyverneresse, // une ancienne mine d'uranium.
Ici, du béryl jaune, // un silicate de béryllium et d'aluminium.
C'est le minéral de l'émeraude // et de l'aigue-marine.
Et l'autunite, // un phosphate d'uranium jaune-vert.
Elle tire son nom d'Autun, // et brille sous les ultraviolets.
Enfin, Vallière // et le Gour de Vaux.
Un chaos de granite // traversé par le Thaurion.
Ici, de l'améthyste, // le quartz violet.
Sa couleur vient du fer // et d'une irradiation naturelle.
Dix gisements, // autant de visages de la Creuse.
Collection jeremineralogie.
