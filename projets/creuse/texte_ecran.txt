Minéraux de la Creuse : // dix gisements de ma collection.
Premier arrêt au nord : // Crozant, aux portes de la vallée des peintres.
Ici, une calcédoine rouge en mamelons, // une variété de quartz.
Elle est formée d'un assemblage de microcristaux, // invisibles à l'œil nu.
Elle se dépose en couches successives, // d'où ces formes arrondies, dites botryoïdales.
Sa teinte rouge // vient de l'oxyde de fer.
Tout près, à Anzême, // une trouvaille anecdotique, mais je tenais à la montrer.
Ce sont des cubes de fluorite, // un fluorure de calcium.
Sur l'échelle de Mohs, // elle sert de référence pour la dureté 4.
À l'est, Montebras, // sur la commune de Soumans.
Son étain est exploité // dès l'Antiquité, selon les sources.
De 1868 à 1914, ses mines // livrent environ 300 tonnes d'étain.
Le gisement a donné son nom à un minéral, // la montebrasite, un phosphate de lithium.
Ici, un grand cristal de quartz, // fait de silicium et d'oxygène.
C'est le minéral le plus abondant de la croûte terrestre, // après les feldspaths.
Voici de l'apatite violette, // un phosphate de calcium.
C'est la même famille de minéraux // que celle de nos os et de nos dents.
Ici, elle est riche en manganèse.
La turquoise et la wavellite // naissent de l'altération de la montebrasite.
La turquoise doit son bleu-vert // au cuivre.
La wavellite pousse en fines aiguilles, // groupées en gerbes rayonnantes.
Et voici une fluorite violet très sombre, // posée sur un tapis rosé de dolomite.
À l'ouest, Janaillat // et son granite orbiculaire.
Une roche rare : // des boules, les orbicules, prises dans le granite.
Chacune est faite de couches concentriques, // claires et sombres.
Au centre, Lavaveix-les-Mines, // un village né du charbon.
Concédé en 1817, // le bassin est exploité jusqu'en 1969.
La production culmine en 1874, // à 354 000 tonnes.
En 1876, la compagnie // emploie 2 000 ouvriers.
La mine produisait même // sa propre électricité.
Dans ma collection, cette pyrite, // très rare ici.
C'est un sulfure de fer // à l'éclat doré, surnommé l'or des fous.
Tout près, une carrière d'Ahun // a livré cette calcite, un carbonate de calcium.
Elle porte de l'analcime, // en petits cristaux blancs.
Chacun compte 24 faces, // presque une sphère.
À l'est, Saint-Silvain-Bellegarde // et sa carrière de granite.
Ici, une gerbe de cristaux de quartz, // dont les pointes sont coiffées d'oxyde de fer.
Puis de la calcite, // en cristaux blancs.
Au sud-est, Flayat // et l'étang de la Ramade.
Sa fluorite violette // forme un tapis de petits cristaux scintillants.
À Gioux, Hyverneresse, // une ancienne mine d'uranium.
Ici, du béryl, // un silicate de béryllium et d'aluminium.
Il cristallise en prismes à six faces.
Vert, c'est l'émeraude ; // bleu, l'aigue-marine ; jaune, l'héliodore.
Et voici l'autunite, // un phosphate d'uranium et de calcium.
Elle tire son nom d'Autun, // et brille en vert sous les ultraviolets.
Enfin, Vallière // et le Gour de Vaux.
Un chaos de blocs de granite, // traversé par le Thaurion.
Ici, de l'améthyste, // la variété violette du quartz.
Sa couleur vient de traces de fer, // transformées par une radioactivité naturelle.
Dix gisements, // autant de visages de la Creuse.
Collection jeremineralogie.
