# Promo jeremineralogie.fr (23 s, 1080 × 1920)

Uniquement des éléments réels du site : captures des pages (format téléphone, 1 080 px de large), photos publiées (fluorite d'Ussel, quartz d'Échassières), logo officiel. Pas de titres à l'écran (choix de l'auteur) : sous-titres karaoké de la voix, puis logo et adresse.

1. Captures des pages : Playwright, viewport 360 × 640, échelle 3 (`sources/captures/`, non versionné).
2. `python3 voix.py` : voix de synthèse (`fr-FR-RemyMultilingualNeural`), phrases placées aux instants du découpage. À signaler comme générée par IA.
3. `python3 musique.py` : musique originale synthétisée, calée sur les transitions.
4. `python3 montage.py` : montage, puis `exports/PROMO_JEREMINERALOGIE.mp4`. Aperçus : `python3 montage.py apercu 1,9.6,20`.

Chiffres dits (relevés sur le site le 14/11/2026) : 38 spécimens dans la collection, 81 pièces disponibles en boutique. À mettre à jour si la vidéo est refaite.
